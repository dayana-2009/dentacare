# DentaCare — Сайт стоматологии

## Краткое описание
Адаптивный одностраничный сайт стоматологии, выполненный в рамках индивидуального задания. 
В проекте реализован калькулятор стоимости услуг, валидация форм, переключение тем (с сохранением в localStorage), мультиязычность (RU/EN), слайдер отзывов, поиск по услугам, страница 404 и модальные окна.
